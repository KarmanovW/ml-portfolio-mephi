# Предсказание критической температуры сверхпроводников

Регрессия: по химическому составу материала предсказать температуру, ниже которой
он теряет электрическое сопротивление.

Практический смысл — сузить перебор при поиске новых высокотемпературных
сверхпроводников: синтезировать и измерять каждый кандидат дорого, а модель
позволяет ранжировать составы до эксперимента.

## Данные

21 263 материала, 81 признак. Признаки описывают химический состав через
агрегаты по элементам: количество элементов в формуле, средние и взвешенные
средние атомных масс, радиусов, электроотрицательностей, теплопроводностей,
плюс энтропия распределения элементов в формуле.

Целевая переменная — критическая температура в кельвинах. Пропусков нет.
Источник — датасет соревнования на Kaggle.

## Подход

Градиентный бустинг (XGBoost) с подбором гиперпараметров через Optuna по RMSE
на 3-кратной кросс-валидации.

Нормализация не применялась намеренно: решающие деревья инвариантны к
монотонным преобразованиям признаков, масштабирование им ничего не даёт.

Пространство поиска: `max_depth` 5-8, `n_estimators` 120-200,
`min_child_weight` 1-100, `subsample` и `colsample_bytree` 0.5-1.0,
`reg_alpha` и `reg_lambda` 0-1. Обучение на GPU (`tree_method="hist"`).

Интерпретация — через SHAP: `TreeExplainer` на подвыборке из 10 000 материалов,
summary plot показывает, какие характеристики состава модель считает главными.

## Результат

Подобранная конфигурация даёт лучший RMSE на кросс-валидации, чем конфигурация
по умолчанию.

Что стоит сказать честно: распределение целевой переменной сильно скошено —
большинство материалов имеют низкую критическую температуру, а
высокотемпературные встречаются редко. RMSE в такой ситуации усредняет ошибку по
всему диапазону и почти не штрафует за промахи именно там, где задача практически
интересна. Правильнее было бы смотреть отдельно на ошибку в верхнем хвосте
распределения или перейти к предсказанию логарифма температуры.

## Что дальше

1. Разложить ошибку по диапазонам критической температуры — сейчас непонятно,
   где именно модель ошибается.
2. Логарифмировать целевую переменную и сравнить.
3. Извлекать признаки из самой химической формулы (парсинг стехиометрии, доля
   элементов по группам таблицы Менделеева), а не полагаться только на готовые
   агрегаты.
4. Сопоставить SHAP-выводы с физикой: согласуется ли то, что модель считает
   главным, с известными закономерностями сверхпроводимости.
