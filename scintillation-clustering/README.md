# Кластеризация сигналов сцинтилляционного детектора

Разделить сигналы органического сцинтиллятора на два физических типа — гамма-
кванты и нейтроны — без использования меток.

Данные предоставлены лабораторией НИЯУ МИФИ: 23 479 сигналов, каждый описан
набором числовых характеристик формы импульса.

## Физика задачи

Сцинтилляционные детекторы на органических кристаллах (паратерфенил и
аналогичные) применяются для регистрации нейтронов в присутствии гамма-фона.
Нейтрон регистрируется через упругое рассеяние на ядрах водорода: ядро отдачи
теряет энергию и вызывает вспышку. Гамма-квант взаимодействует иначе, через
комптоновские электроны.

Из-за разной плотности ионизации форма импульса у этих двух процессов
различается — у нейтронов доля «медленной» компоненты свечения выше. На этом
различии и строится разделение.

## Почему обучение без учителя

Метки классов в эксперименте недоступны: физически определить тип каждой
отдельной вспышки нельзя, для этого нужен отдельный эталонный источник.
Разделение по форме импульса — это и есть способ получить метки, а не задача
классификации с известными ответами.

Дополнительный аргумент: сигналы шумные, классы частично пересекаются по
энергии, и часть событий не относится однозначно ни к одному типу.

## Подход

1. Стандартизация признаков (`StandardScaler`) — обязательна, потому что
   характеристики импульса измеряются в разных единицах и на разных масштабах,
   а расстояние в KMeans чувствительно к масштабу.
2. PCA — для визуализации структуры данных в двух измерениях и оценки того,
   насколько классы вообще разделимы.
3. KMeans (k=2) и DBSCAN — сравнение.

## Результат

Лучше отработал KMeans: он даёт устойчивое разбиение на два сопоставимых по
размеру кластера, что соответствует физической постановке. DBSCAN на этих данных
плохо подбирается по плотности — кластеры сильно различаются по плотности, и
единый параметр `eps` либо схлопывает всё в один кластер, либо отправляет
большую часть точек в шум.

Качество оценено через accuracy после сопоставления кластеров реальным типам
сигналов на подмножестве, где типы известны.

## Ограничение

Accuracy при кластеризации зависит от того, как сопоставлены номера кластеров
классам, и это сопоставление делается уже по меткам. То есть метрика показывает,
насколько найденное разбиение совпадает с физическим, но не является честной
оценкой качества «без учителя». Дополнительно стоило бы привести silhouette
score, который меток не требует.
