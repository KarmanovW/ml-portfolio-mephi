## Основные проекты

### [Приоритизация обращений (Avito)](avito-lead-prioritization/)
Ранжирование назначенных обращений по вероятности целевого действия.
Метрика — Daily Average Precision. Признаки из событийного лога с защитой от
утечки по времени, time-series CV с расширяющимся окном, ансамбль из девяти
моделей трёх семейств с ранговым смешиванием.
`LightGBM · CatBoost · XGBoost · Optuna`

### [Извлечение атрибутов из поисковых запросов](wb-query-attributes/)
NER-задача на запросах маркетплейса: бренд, категория, цвет, пол, размер.
Словарный экстрактор даёт F1 0.93 по категории на ручной разметке. Поверх —
гибрид с NER, обученным на LLM-разметке: на длинном хвосте он поднимает
категорию с 0.464 до 0.530, но на случайной выборке всё портит. Разобрано,
почему, и в каком режиме гибрид применим.
`Transformers · rubert-tiny2 · seqeval · Groq API`

### [Детекция чаек на аэрофотоснимках](seagull-detection-yolov8/)
Одноклассовая детекция мелких объектов. mAP@0.5 = 0.843 при mAP@0.5:0.95 = 0.397
— разрыв разобран в README.
`YOLOv8 · OpenCV`

### [Мультилейбловая классификация видео](video-multilabel-classification/)
Девять тегов, покадровый ResNet50 с temporal pooling, подбор порога на класс
(+9 п.п. к F1-macro). Итог: F1-macro 0.689, Kaggle 0.885 private. Основная
метрика — F1-macro: по accuracy константный предсказатель даёт 0.883 против
0.927 у модели, то есть эта метрика решения почти не различает.
`PyTorch · torchvision · OpenCV`

### [Персонализация Stable Diffusion XL через LoRA](sdxl-lora-finetuning/)
Дообучение генеративной модели на конкретного человека: обучается меньше
процента параметров, всё помещается в 16 ГБ. Сила адаптера подбирается по
косинусной близости эмбеддингов лиц на фиксированных сидах, а не на глаз.
Изображения и веса не публикуются — это персональные данные.
`Diffusers · PEFT · bitsandbytes · xFormers`

### [Прогнозирование попадания в сборную](badminton-team-prediction/)
Научно-исследовательская работа: собственный датасет из анкет и физических
тестов. Найдена и измерена утечка через отбор признаков до кросс-валидации
(+18.7 п.п. к accuracy). Дальше — работа с данными вместо подбора моделей:
фильтр по заполненности отсекал 21 наблюдение из 51, а пропуски оказались
информативными. Тематические индексы вернули данные в анализ и подняли ROC-AUC
с 0.709 до 0.835 при p = 0.005 в перестановочном тесте.
`scikit-learn · pandas`
